# 新建课程

1. 登录教师/管理端，点击左侧导航的“课程管理”。
2. 在“我的课程”标题右侧点击“＋”，打开“新增课程”窗口。

![“我的课程”右侧的新增课程按钮](../../../../img/新增课程按钮位置.png)

3. 填写“课程名称”；“课程描述”为选填项，可以按需补充。
4. 点击“创建”。如果暂时不创建，可点击“取消”或窗口右上角的关闭按钮。

![新增课程窗口中的课程名称、课程描述和创建按钮](../../../../img/新课程信息填写.png)

课程创建后，可以在该课程下[新建考试](../../exam/create/)；需要邀请学生时，参照[邀请操作](../../invitation/)。
