# 新建考试

1. 点击左侧导航的“课程管理”，从“我的课程”列表中选择考试所属的课程。
2. 点击课程详情右上角的“＋ 新增考试”，打开“新增考试”窗口。

![选中课程后，课程详情右上角的新增考试按钮](../../../../img/新增考试按钮位.png)

3. 在窗口左侧填写“考试名称”，按需填写“考试描述”。设置“考试类型”“是否需要代码仓库”“报告模板”和“考试有效时间”。有效时间输入框分别以“天”和“时”为单位。
4. 在窗口右侧按需配置 Agent 模型：出题模型、主评判模型、语音模型和评判模型组。语音模型用于考试语音合成；界面提示需要先在“模型设置”中添加 TTS 类型模型。
5. 核对配置后点击“创建”；若不保存，点击“取消”或窗口右上角的关闭按钮。

![新增考试窗口及其考试信息和 Agent 模型配置](../../../../img/编辑、新增考试页面.png)

提交后，可返回当前课程的考试列表确认新考试是否出现。

考试建立在选中的课程下。上述截图未展示题目维度、参考资料和预设题的配置入口，这些内容以实际界面为准。
