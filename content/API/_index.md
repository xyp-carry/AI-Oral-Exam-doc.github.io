# API

本页整理认证与用户相关接口。接口说明按小标题展开，方便后续继续补充请求示例、返回示例和错误码。

## 根路径

### GET /

认证：不需要登录。

请求内容：无。

返回内容：系统基础信息，以及主要接口入口提示。

用途：用于快速确认服务入口是否可访问，并查看系统对外暴露的主要端点。

## 健康检查

### GET /health

认证：不需要登录。

请求内容：无。

返回内容：服务健康状态，以及服务端当前时间。

用途：用于监控服务是否正常运行。

## 用户注册

### POST /register

认证：不需要登录。

请求内容：用户名、密码、邮箱、角色、昵称。昵称可以不传；角色只支持教师或学生。

返回内容：注册结果、用户基础信息、账号是否需要激活等提示信息。

用途：注册新用户。新账号默认需要激活后才能登录。

## 用户登录

### POST /login

认证：不需要登录。

请求内容：用户名、密码、是否记住登录状态。

返回内容：登录结果、当前用户基础信息，并在浏览器中写入会话 Cookie。

用途：完成账号登录，让后续接口可以通过 Cookie 会话识别当前用户。

## 用户注销

### POST /logout

认证：可选。已登录时会注销当前设备会话；未登录时也会清理 Cookie。

请求内容：当前浏览器携带的 Cookie 会话。

返回内容：注销结果，以及 Cookie 清理结果。

用途：注销当前设备会话并清除登录状态。

## 当前用户信息

### GET /me

认证：需要登录。

请求内容：无。

返回内容：当前登录用户的账号、邮箱、角色、昵称、状态等基础信息。

用途：获取当前登录用户信息，常用于前端初始化用户状态。

## 用户列表

### GET /users

认证：需要登录。

请求内容：无。

返回内容：用户列表，以及系统中的用户总数。

用途：获取用户列表和用户总数。

## 更新个人资料

### PUT /profile

认证：需要登录。

请求内容：邮箱、昵称。两个内容都可以按需更新。

返回内容：更新结果，以及更新后的用户基础信息。

用途：更新当前用户邮箱或昵称。

## 修改密码

### PUT /password

认证：需要登录。

请求内容：旧密码、新密码。

返回内容：密码修改结果，以及会话注销提示。

用途：修改当前账号密码。修改成功后会注销所有设备，需要重新登录。

## 活跃会话列表

### GET /sessions

认证：需要登录。

请求内容：无。

返回内容：当前用户所有活跃会话，包括设备、登录时间、过期时间等会话信息。

用途：查看当前用户所有活跃会话。

## 注销其他设备

### DELETE /sessions

认证：需要登录。

请求内容：无。

返回内容：注销结果，以及当前设备的新会话信息。

用途：注销其他设备，会重新保留当前设备会话。

## 删除账号

### DELETE /account

认证：需要登录。

请求内容：无。

返回内容：账号删除结果，以及会话清理结果。

用途：删除当前用户账号及会话。

## 系统统计

### GET /stats

认证：需要登录。

请求内容：无。

返回内容：系统用户数量、活跃会话数量等统计信息。

用途：查看系统用户和会话统计。

## 网关代理

### POST /gateway

认证：需要登录。

请求内容：目标服务地址、请求方法、请求头、请求体、查询参数。请求方法默认使用 GET；请求头、请求体和查询参数可以按需传入。

返回内容：目标服务返回的响应结果，以及代理调用状态。

用途：认证后代理请求到目标服务。
